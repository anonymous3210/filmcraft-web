FilmCraft Web — app estático compilado

Extraia este ZIP e execute executar-filmcraft-web.bat (Windows) ou ./executar-filmcraft-web.sh (macOS/Linux). Também funciona com: python run_filmcraft_web.py. Requer Python 3.7+. O script serve o app em http://127.0.0.1:8000/; abra a URL no navegador de sua preferência e mantenha o terminal aberto. Use --port 8080 para outra porta ou --open para abrir o navegador padrão.
